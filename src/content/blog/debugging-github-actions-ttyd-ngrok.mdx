### Setup (30 seconds)

**1. Get ngrok token:** [ngrok.com/signup](https://dashboard.ngrok.com/signup) (free)

**2. Add secrets:**

```bash
gh secret set NGROK_AUTHTOKEN
gh secret set DEBUG_SESSION_PASSWORD
```

**3. Add to workflow:**

```yaml
- if: failure()
  uses: halradaideh/ttyd-ngrok-debug@v0.0.1
  with:
    ngrok_authtoken: ${{ secrets.NGROK_AUTHTOKEN }}
    password: ${{ secrets.DEBUG_SESSION_PASSWORD }}
```

**Done.** Next failure → logs show URL → click → debug → close with:

```bash
touch /tmp/terminate_debugging
```

### Example: Debug Failing Tests

```yaml
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm test

      - if: failure()
        uses: halradaideh/ttyd-ngrok-debug@v0.0.1
        with:
          ngrok_authtoken: ${{ secrets.NGROK_AUTHTOKEN }}
```

**In browser terminal:**

```bash
npm test -- --verbose
env | grep NODE
node --inspect test/failing.js
```

### Pro Tips

**Manual trigger:**
```yaml
on: [push, workflow_dispatch]
- if: github.event_name == 'workflow_dispatch'
  uses: halradaideh/ttyd-ngrok-debug@v0.0.1
````

**Debug specific OS:**

```yaml
- if: matrix.os == 'macos-latest' && failure()
  uses: halradaideh/ttyd-ngrok-debug@v0.0.1
```

**tmux shortcuts:**

```
Ctrl+b "  → split horizontal
Ctrl+b %  → split vertical
Ctrl+b c  → new window
```

### How It Works

Three static binaries run on your runner:

- **ttyd** - Web terminal
- **tmux** - Persistent session
- **ngrok** - Secure tunnel
